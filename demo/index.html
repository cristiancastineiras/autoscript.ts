Pruebas de AutoScript

Páginas de prueba del repositorio oficial de Autofirma, ejecutadas con autoscript.js generado desde TypeScript. Requieren Autofirma instalado.

IMPORTANTE: acceda siempre mediante una IP o un nombre de dominio, nunca localhost ni 127.0.0.1; si no, Autofirma bloqueará la firma.

Interfaz clásica (autoscript.js)
  • Firma, cofirma, contrafirma, certificados y ficheros
  • Firma de lotes JSON (trifásica y local)
  • Firma de lotes XML (mecanismo heredado)

SDK moderno (módulos ES y promesas)
  • Firma con createAutoFirmaClient()
